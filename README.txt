Как подключить Google Таблицу:
1. Создай Google Таблицу.
2. Открой Extensions / Расширения → Apps Script.
3. Вставь содержимое файла google-apps-script.js.
4. Нажми Deploy / Развернуть → New deployment / Новое развертывание.
5. Тип: Web app / Веб-приложение.
6. Execute as / Выполнять от имени: Me / Я.
7. Who has access / У кого есть доступ: Anyone / Все.
8. Скопируй Web app URL.
9. Открой script.js и вставь URL сюда:

   const GOOGLE_SHEETS_WEB_APP_URL = "ТВОЙ_URL_СЮДА";

10. Загрузи проект на хостинг и проверь отправку после финального выбора мороженого.

Важно:
IP и user agent относятся к персональным/техническим данным во многих юрисдикциях.
Не собирай больше, чем нужно, не скрывай сбор данных и не публикуй таблицу в открытом доступе.
